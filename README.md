# Homebrew tap

Formulas for [voxdesk](https://github.com/YashSharmaa/voxdesk) and [speakback](https://github.com/YashSharmaa/speakback). Each one builds from source on your Mac.

```sh
brew tap YashSharmaa/tap
brew install speakback   # the speak command and its agent skills
brew install voxdesk     # hotkey dictation app; follow the caveat to copy it to /Applications
```

You need an Apple Silicon Mac, macOS 14 or later, and the Xcode command line tools.
